# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/b350dc46-90ea-4617-a05b-eff54a7c2d43

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY` and `CJ_ACCESS_TOKEN`. Keep the CJ token server-side; do not add it to frontend code.
3. Run the app:
   `npm run dev`
